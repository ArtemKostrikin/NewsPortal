# NewsPortal

Новостной портал на Django с системой авторов, категорий, подписок и рейтингов.

## Функционал
- Статьи и новости с рейтингами
- Авторы с автоматическим подсчётом рейтинга
- Подписка на категории
- Фильтрация и поиск
- Ролевая система (авторы, читатели)
- Celery для асинхронных задач

## Стек
- Django
- SQLite
- Celery

## Запуск

```bash
python manage.py migrate
python manage.py runserver
